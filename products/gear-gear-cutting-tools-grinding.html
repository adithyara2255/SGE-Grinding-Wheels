Gear & Gear Cutting Tools Grinding

SGE Grinding Wheels provides high-performance grinding wheel solutions for gear manufacturing, gear cutting tools and precision tool grinding applications.

Applications

The wheel configurations are selected according to the specific gear or cutting-tool grinding application.

  • Single-rib gear teeth grinding using Q-face wheels
  • Multi-rib gear grinding using multi-profile gear grinding
  • Straight cup wheels for bevel gear grinding
  • Blank grinding wheels for gear honing
  • Hob resharpening
  • Broach grinding
  • Tool and cutter grinding
